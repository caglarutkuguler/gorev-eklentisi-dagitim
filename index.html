Görev Eklentisi

NCU Task Tracker

Outlook'ta e-posta gönderir gibi görev verin; kabul, iş kaydı ve tamamlama adımlarını liste, kanban ve Gantt ile izleyin.

Assign tasks in Outlook as easily as sending an e-mail; follow accept, work log and complete steps in list, Kanban and Gantt views.

Hangi Outlook'u kullanıyorsunuz?Which Outlook do you use?

Windows

Klasik Outlook 2016 · 2019 · 2021 · Microsoft 365Classic Outlook 2016 · 2019 · 2021 · Microsoft 365

Kurulum dosyasını indirDownload the installer GorevEklentisi-Kurulum.exe
  1. İndirilen dosya çift tıklanır.
  2. "Windows kişisel bilgisayarınızı korudu" uyarısında Ek bilgi → Yine de çalıştır (neden çıkar?), yönetici onayında Evet.
  3. Kurulum bitince Kapat; Outlook açılır, Giriş sekmesinde Görev grubu görünür.
  1. Double-click the downloaded file.
  2. If "Windows protected your PC" appears, select More info → Run anyway (why?), then Yes at the administrator prompt.
  3. When setup finishes, select Close; Outlook opens and the Görev (Task) group appears on the Home tab.

Her tür hesapla çalışır (Exchange, Microsoft 365, IMAP, POP). Kurulum Outlook'u kapatır; kaydedilmemiş taslaklar önce kaydedilir.

Works with every account type (Exchange, Microsoft 365, IMAP, POP). The Windows desktop edition has a Turkish interface. Setup closes Outlook; save any unsaved drafts first.

Mac · yeni Outlook · Outlook webMac · new Outlook · Outlook on the web

macOS için Outlook, Windows'ta yeni Outlook, outlook.office.com, outlook.comOutlook for Mac, new Outlook for Windows, outlook.office.com, outlook.com

Eklenti dosyasını indirDownload the add-in file GorevEklentisi-manifest.xml
  1. Dosya indirilir (açılmaz; yalnızca Outlook'a yüklenir).
  2. Outlook'un Eklentiler penceresi açılır: iş / okul hesabı ya da kişisel hesap (Outlook.com). Bağlantı pencereyi açmazsa Outlook'ta bir ileti açılıp Uygulamalar → Eklenti al seçilir.
  3. Eklentilerim → Özel eklentiler → Özel eklenti ekle → Dosyadan ekle ile indirilen dosya seçilir, Yükle denir.
  4. Bir ileti açılır; iletideki Uygulamalar düğmesinden Görev Eklentisi seçilir.
  1. Download the file (do not open it; it is only uploaded to Outlook).
  2. Open Outlook's Add-ins window: work / school account or personal account (Outlook.com). If the link does not open it, open a message in Outlook and select Apps → Get Add-ins.
  3. Select My add-ins → Custom Addins → Add a custom add-in → Add from File, choose the downloaded file and select Install.
  4. Open a message and select NCU Task Tracker from the Apps button in the message.

Microsoft 365 ya da Outlook.com posta kutusu gerekir. Bir kez eklenince aynı hesapla web, Mac ve yeni Outlook'ta görünür.

Requires a Microsoft 365 or Outlook.com mailbox. Once added, it appears on the web, on Mac and in new Outlook for the same account. English and Turkish interface.

TarayıcıBrowser

Linux, ChromeOS ve Outlook kurulu olmayan bilgisayarlarLinux, ChromeOS and computers without Outlook

Tarayıcıda açOpen in the browser kurulum gerekmezno installation needed
  1. Sayfa açılır, Microsoft hesabıyla oturum aç denir.
  2. İlk girişte istenen izinler onaylanır.
  3. İstenirse sayfa yer imlerine ya da tarayıcının "uygulama olarak yükle" seçeneğiyle masaüstüne eklenir.
  1. Open the page and select Sign in with a Microsoft account.
  2. Approve the requested permissions at first sign-in.
  3. Optionally bookmark the page or add it to the desktop with the browser's "install as app" option.

Microsoft 365 ya da Outlook.com posta kutusu gerekir. Outlook'a eklenti kuranlar için de geniş ekran görünümüdür (kanban, Gantt).

Requires a Microsoft 365 or Outlook.com mailbox. Also the wide-screen view (Kanban, Gantt) for those who use the add-in in Outlook.
