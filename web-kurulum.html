Görev Eklentisi — Web sürümü (Mac, Outlook web, yeni Outlook, tarayıcı)

Windows'taki klasik Outlook için kurulum paketi (VSTO eklentisi) kullanılır. Diğer platformlar için aynı görev sistemi bir Office web eklentisi ve tarayıcı uygulaması olarak çalışır. İki sürüm aynı görev maillerini okuyup yazar; kullanıcılar hangi sürümü kullanırsa kullansın birbirine görev verebilir.

PlatformKullanılan sürüm
Windows — klasik Outlook 2016 / 2019 / 2021 / Microsoft 365Kurulum paketi (GorevEklentisi-Kurulum.exe)
Windows — yeni OutlookWeb eklentisi
macOS — OutlookWeb eklentisi
Outlook web (outlook.office.com, outlook.com) — her işletim sistemiWeb eklentisi
Linux ve diğerleri (Outlook kurulu olmadan)Tarayıcı uygulaması

Koşul: posta kutusu Microsoft 365 (Exchange Online) ya da Outlook.com olmalıdır. IMAP / POP / Gmail hesapları web sürümünde desteklenmez (Outlook bu hesaplarda web eklentisi yüklemez; tarayıcı uygulaması da posta kutusuna Microsoft Graph ile erişir). Bu hesaplar yalnızca Windows'taki kurulum paketiyle kullanılabilir.

Adresler (yayın adresi web-eklenti/yayin.json → taban):

  • İndirme sayfası: https://caglarutkuguler.github.io/gorev-eklentisi-dagitim/
  • Tarayıcı uygulaması: https://caglarutkuguler.github.io/gorev-eklentisi-dagitim/eklenti/
  • Eklenti dosyası (manifest): https://caglarutkuguler.github.io/gorev-eklentisi-dagitim/eklenti/manifest.xml

1. Bir kerelik kurulum (yayıncı)

1.1 GitHub Pages

Dağıtım deposunda Settings → Pages → Build and deployment → Source: Deploy from a branch, dal main, klasör / (root) seçilip kaydedilir. Birkaç dakika sonra yukarıdaki adresler açılır. Sonraki derlemeler siteyi kendiliğinden günceller.

1.2 Uygulama kaydı (Microsoft Entra)

Eklenti posta kutusuna kullanıcının kendi oturumuyla (Microsoft Graph) erişir; bunun için bir uygulama kaydı gerekir. Kayıt ücretsizdir, sunucu ya da gizli anahtar içermez.

  1. https://entra.microsoft.com → Applications → App registrations → New registration.
  2. Name: Görev Eklentisi. Supported account types: Accounts in any organizational directory and personal Microsoft accounts.
  3. Redirect URI: platform Single-page application (SPA), adres https://caglarutkuguler.github.io/gorev-eklentisi-dagitim/eklenti/index.html → Register.
  4. Authentication → Single-page application → Add URI: brk-multihub://caglarutkuguler.github.io (Outlook içindeki oturum için) → Save.
  5. API permissions → Add a permission → Microsoft Graph → Delegated permissions: User.Read, Mail.ReadWrite, Mail.Send, People.Read → Add permissions.
  6. Overview sayfasındaki Application (client) ID değeri web-eklenti/yayin.json dosyasındaki istemciKimligi alanına yazılır ve derleme yeniden çalıştırılır. Bu değer gizli değildir.

Kimlik tanımlanana kadar uygulama "Kurulum tamamlanmadı" iletisini gösterir.

Kullanıcı onayına izin vermeyen kurumlarda bir yöneticinin izinleri kurum adına onaylaması gerekir (Entra → Enterprise applications → Görev Eklentisi → Permissions → Grant admin consent).

2. Eklentiyi Outlook'a ekleme

Kullanıcı kendisi ekler (Outlook web, yeni Outlook, Mac):

  1. Eklenti dosyası (manifest.xml) indirme sayfasından indirilir: https://caglarutkuguler.github.io/gorev-eklentisi-dagitim/
  2. Outlook'un "Eklentiler" penceresi açılır. Tarayıcıda, eklentinin ekleneceği hesapla oturum açıkken:
    • iş / okul hesabı: https://outlook.office.com/mail/inclientstore
    • kişisel hesap (Outlook.com, Hotmail): https://outlook.live.com/mail/0/inclientstore
    • bağlantı pencereyi açmazsa: Outlook'ta bir ileti açılır, iletinin üstündeki Uygulamalar düğmesinden Eklenti al seçilir.

Pencere yalnızca Outlook posta kutusu olan hesaplarda açılır. Posta kutusu (Exchange Online lisansı) olmayan bir Microsoft hesabıyla oturum açıksa bağlantılar boş sayfa ya da hata gösterir.

  1. Eklentilerim → Özel eklentiler → Özel eklenti ekle → Dosyadan ekle ile indirilen manifest.xml seçilir, Yükle denir.

Kurum genelinde (Microsoft 365 yöneticisi): Microsoft 365 yönetim merkezi → Ayarlar → Tümleşik uygulamalar → Özel uygulamaları karşıya yükle → Office Eklentisi → bildirim dosyası bağlantısı olarak manifest.xml adresi verilir, kullanıcılar/gruplar seçilir. Eklenti seçilen herkesin Outlook'unda (web, Mac, yeni ve klasik) kendiliğinden görünür.

Eklenti bir ileti açıkken Görev grubundaki (ya da iletideki Uygulamalar menüsündeki) Görevler ve Yeni Görev düğmeleriyle açılır. İlk kullanımda Microsoft'un izin onayı penceresi bir kez çıkar.

Outlook olmadan (Linux vb.): tarayıcı uygulamasının adresi açılır, Microsoft hesabıyla oturum aç denir.

3. Nasıl çalışır

  • Sunucu bileşeni yoktur. Görevler posta kutusundaki görev maillerinden okunur (Gelen Kutusu, Görevler klasörü, Gönderilmiş Öğeler) ve tarayıcıda yerel olarak saklanır; işlemler görev maili olarak gönderilir.
  • Pencere açıkken iki dakikada bir ve ⟳ düğmesiyle eşitlenir. Web eklentileri arka planda çalışamadığından yeni görev bildirimi çıkmaz; görev maili Gelen Kutusu'na normal e-posta olarak düşer.
  • Bağlantı yokken yapılan işlemler bekletilir, bağlantı gelince gönderilir.
  • Aynı posta kutusu hem Windows eklentisiyle hem web sürümüyle kullanılabilir: biri diğerinin yaptığı işlemleri Gönderilmiş Öğeler'den okur.
  • Görev maillerindeki Kabul Et / İş Kaydı… düğmeleri yalnızca Windows eklentisinde çalışır; web sürümünde bölmedeki düğmeler kullanılır.

5. Geliştirme

  • Kaynak: web-eklenti/kaynak/ (çekirdek, depo, servis, Graph, formlar, köprü). Liste / kanban / Gantt / yük arayüzü Windows eklentisiyle ortaktır: src/GorevEklentisi.Addin/web/.
  • cekirdek.js, GorevEklentisi.Core'un (C#) karşılığıdır; olay modeli, kurallar ya da mail biçimi değişince iki taraf birlikte güncellenir.
  • Derleme: node web-eklenti/derle.mjs --taban <https adresi> --surum a.b.c --istemci <uygulama kimliği> → web-eklenti/dist/.
  • Testler: node --test web-eklenti/test/akis.test.mjs (çekirdek + servis, sahte posta); node web-eklenti/test/arayuz.mjs (Playwright ile arayüz akışı).
